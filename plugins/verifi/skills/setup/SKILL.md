# Getting started with verifi

1. Tell the person, in one or two sentences, that verifi signs in with their own VeriFi account, sees only what their VeriFi permissions allow, and records every request in VeriFi's audit trail.
2. If verifi is not connected yet, ask them to connect it and sign in to VeriFi when prompted. Never ask for a password, client ID or secret.
3. Check the connection with one harmless read from the verifi tools available. If there are none, say their VeriFi account has no assistant tools yet and an administrator can add access.
4. Briefly describe what they can do, based only on the tools available to them, and offer two or three example requests.
5. Explain that verifi reads a record before changing it and asks them to confirm before any change. Nothing can be permanently deleted.
6. If the client-switching tools are available, explain that the selected client applies to every conversation on this connection and expires after 90 minutes, and that you will always say which client you are selecting.
7. Before any multi-step job, such as building an inspection form or setting up a client, read its guide with `verifi_get_guide` if one is listed, and follow it.
